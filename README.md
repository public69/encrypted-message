# رسالة مشفّرة

لعبة ألغاز جماعية لحظية (Multi-Team · Real-Time · Server Authoritative) — الخادم هو المصدر الوحيد للحقيقة.

## التشغيل
```bash
node server/index.js          # المنفذ 3000 أو PORT
npm test                      # 25 اختبارًا (منطق + WebSocket حقيقي)
python3 scripts/ui-smoke.py   # اختبار واجهة على Chromium بقياس iPhone (يتطلب playwright)
```
يتطلب Node 22+ ولا يحتاج `npm install`. للنشر: أي استضافة Node تدعم WebSocket خلف HTTPS
(Render / Railway / Fly.io / VPS + Nginx). اضبط `ALLOWED_ORIGINS` إن كانت الواجهة على نطاق مختلف.

## البنية
| الملف | الدور |
|---|---|
| `server/arabic.js` | Tokenizer + Answer Normalizer الموحّدان |
| `server/puzzle.js` | توليد اللغز + مدقق مستقل (30 بطاقة، 60/40، مسارات، بطاقات مضللة) |
| `server/engine.js` | الغرف والفرق والجولات وآلة الحالات والمؤقت واللقطات المخصصة لكل لاعب |
| `server/ws.js` | خادم WebSocket (RFC 6455) بلا اعتماديات |
| `server/index.js` | HTTP ثابت + توجيه الرسائل + فحص Origin + تحديد المعدل |
| `public/` | واجهة Mobile-First + PWA (manifest + service worker + أيقونات) |

## ضمانات الأمان (مُختبرة)
- محتوى البطاقات والجملة لا يغادران الخادم؛ المحتوى يُرسل للجميع فقط لحظة الكشف ولثانية واحدة.
- كل عملية تُفحص في الخادم: قائد الفريق الحالي فقط، حالة ACTIVE، عدم انتهاء الوقت، بطاقة واحدة في كل مرة، حد مرتين، ترتيب صالح.
- لا تكرار في صندوق الرموز ولا في الشفرة، وكل رمز أو حرف داخل الشفرة مأخوذ حصرًا من صندوق الرموز (فحص وقت تحميل + مدقق مستقل + فحص إعادة الترتيب).
- المؤقت في الخادم (مع فحص كسول عند كل طلب)، ولا يتوقف بأي حدث. إعادة الاتصال تستعيد الحالة دون تصفير شيء.
